# Escopo do projeto é o orquestrador e o contrato de integração, não os agentes

O squad_agentica constrói e opera apenas o orquestrador e o contrato de integração orquestrador↔agente. Os agentes especializados (Refinamento, Execução, QAI, GMUD etc.) são construídos pelo próprio time de modernização de jornadas — não são de times externos —, mas como frentes de desenvolvimento separadas: cada agente evolui no seu ritmo e é plugado ao fluxo assim que fica pronto para consumo. Eles ficam, portanto, fora do escopo de entrega desta orquestração, ainda que sejam do mesmo time.

Consequência direta: o orquestrador não faz nenhuma chamada de LLM própria — sua lógica é determinística (ler xClick, abrir subitens, aplicar a regra do semáforo, montar/despachar jobs, escrever resultados de volta). Decisões de framework de agente e procurement de LLM (Bedrock, proxy interno, etc.) ficam com a frente dona de cada agente. É o contrato que permite construir e testar o orquestrador ponta a ponta antes de qualquer agente existir, e ir substituindo stubs por agentes reais conforme eles amadurecem.
