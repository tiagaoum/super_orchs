Arquitetura e fluxo do orquestrador

Como o orquestrador conduz uma história ou bug pelas raias do xClick, delegando a agentes especializados por meio de um contrato de integração — abrindo um subitem em cada raia e usando o encerramento desse subitem como semáforo para avançar.

20 set 2026 · fonte: CONTEXT.md + ADR-0001–0007 · piloto: 2 squads · v1
01

Arquitetura

O orquestrador não roda nenhum modelo de linguagem — sua lógica é determinística: lê o xClick, abre o subitem da raia, aplica a regra do semáforo, despacha e recebe jobs. A fronteira pontilhada à direita não separa times: os agentes são construídos pelo próprio time de modernização de jornadas, em frentes paralelas. Ela marca onde termina a entrega desta orquestração — cada agente entra no fluxo conforme fica pronto para consumo, e até lá o contrato permite rodar o orquestrador ponta a ponta com stubs.

escopo desta entrega (orquestração) agentes · frentes paralelas do mesmo time integração fora do fluxo principal (ServiceNow) REFIN=Em Refinamento · EXEC=Execução · PROMO=Pronto para QA · QAI=Em Testes QA · GMUD=Em Implantação
ADR-0001 — orquestrador centraliza todo acesso ao xClick.
ADR-0002 — escopo desta entrega para no orquestrador + contrato; agentes são frentes paralelas do mesmo time.
ADR-0003 — integração assíncrona: SNS de entrada com filtro por raia, SQS de saída compartilhada.
ADR-0004 — núcleo é uma execução do Step Functions por item.
ADR-0005 — subitem aberto em cada raia é o semáforo de avanço.
ADR-0006 — raia "Refinado" separa o refinamento do agente do aceite humano.
ADR-0007 — v1 é linear: nenhum item volta para uma raia anterior.
02

Fluxo

Cada item ganha sua própria execução do Step Functions ao sair do Backlog. Em cada raia o orquestrador abre um subitem e só avança quando ele é encerrado — esse é o semáforo. Em três raias quem encerra é uma pessoa: Refinado, Peer Review e Testado QA. Nas demais, o próprio agente encerra ao terminar com sucesso. Na v1 o avanço é estritamente linear: subbug aberto pelo QAI segura o item em Testado QA até o QA encerrá-lo, mas não devolve o item para uma raia anterior.

raia de revisão humana · a pessoa encerra o subitem o agente encerra o subitem ao terminar fora do orquestrador (manual)
